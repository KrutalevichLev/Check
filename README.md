# SIGMA PAY · Платёжная форма

Ванильный JS, ноль зависимостей. Тёмный дизайн в духе «Бойцовского клуба»,
живое 3D-превью карты и полная валидация.

## Запуск

Просто открой `index.html` в браузере, либо:

```bash
python3 -m http.server 8099
# → http://localhost:8099
```

## Что внутри

| Файл | Роль |
|---|---|
| `index.html` | Разметка: ФИО, номер карты, CCV, срок действия, email |
| `style.css` | Тёмная тема, glassmorphism, зерно плёнки, адаптив, анимации |
| `script.js` | Маски ввода, валидация, превью карты, определение ПС |

## Фичи

- **Живая карта-превью** — дублирует ввод; переворачивается при фокусе на CCV (или по клику).
- **Маски**: номер карты группируется по 4, срок — `MM/YY` с авто-слэшем и авто-исправлением месяца, CCV/номер принимают только цифры, ФИО — только буквы.
- **Валидация**: алгоритм Луны для номера, проверка срока (не просрочен, не из 2100-го), формат email, длина CCV 3/4 (Amex), чекбокс согласия. Ошибки — на blur и далее при вводе, плюс shake + подсветка.
- **Определение платёжной системы**: МИР / VISA / MC / AMEX / JCB / DISCOVER.
- **Экран успеха** со спиннером при «отправке» и кнопкой сброса.
- Адаптив под мобилу + `prefers-reduced-motion`.
